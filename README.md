# TIME/UNWIND

## What it's about
Time/Unwind is a timed game where the player has to overcome 10 (not) different levels with different sceneries, where the last one is the same as the first one. Made with Godot.

## How to run it locally
Time/Unwind is available on itch.io at https://othel51.itch.io/timeunwind as a web game! If you happen to want to run it locally or tweak it in any way, you can download the zip file of this repository and open it with Godot!
